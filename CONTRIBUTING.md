# Contributing

Thanks for helping improve Mermaid Flow Editor.

## Before opening a pull request

1. Open an issue for substantial behavior or architecture changes.
2. Keep changes focused and avoid committing `.env`, database, or generated
   files.
3. Use Node.js 22.12 or newer and install dependencies with `npm ci`.
4. Run `npm test` and `npm run build`.
5. Add or update tests for server, proxy, export, and security behavior.

Use clear commit messages and describe user-visible behavior, security impact,
and validation in the pull request. By contributing, you agree that your work
is licensed under the MIT License.
